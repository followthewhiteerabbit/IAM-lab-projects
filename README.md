# IAM Lab Projects

A collection of hands-on identity and access management labs built in Microsoft Entra ID (Azure AD), demonstrating real-world Conditional Access design, MFA enforcement, risk-based policies, and Zero Trust principles.

---

## Labs

| # | Lab | Topics |
|---|-----|--------|
| 01 | [Dynamic Group MFA Policy](./lab-01-dynamic-group-mfa-policy/README.md) | Dynamic groups, Conditional Access, MFA enforcement |
| 02 | [Compliant Device Conditional Access](./lab-02-compliant-device-conditional-access/README.md) | Intune, device compliance, Zero Trust |
| 03 | [Block Legacy Authentication](./lab-03-block-legacy-authentication/README.md) | Legacy auth, Conditional Access, modern auth |
| 04 | [Sign-In Risk Based MFA](./lab-04-sign-in-risk-mfa-conditional-access/README.md) | Identity Protection, sign-in risk, adaptive MFA |
| 05 | [High-Risk User Password Reset](./lab-05-user-risk-password-reset/README.md) | Identity Protection, user risk, self-service password reset |

---

## Skills Demonstrated

- Microsoft Entra ID (Azure AD)
- Conditional Access policy design and testing
- Multi-Factor Authentication (MFA)
- Microsoft Intune device compliance
- Identity Protection (sign-in risk & user risk)
- Dynamic group membership rules
- Zero Trust security principles

---

## Platform

All labs were built and validated in a live Microsoft Entra ID tenant using real users, groups, and policy assignments.
